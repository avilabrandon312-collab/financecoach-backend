# FinanceCoach - Backend & Servicios Web Integrated System

Sistema de gestión financiera personal desarrollado como parte de la formación ADSO (SENA). Incluye servicios de backend en PHP, persistencia en MySQL y servicios web SOAP para conversión de divisas.

## 🚀 Requisitos del Sistema
* XAMPP Server (PHP 8.x + MySQL)
* Composer (Opcional)
* Postman / Insomnia para pruebas de servicios web
